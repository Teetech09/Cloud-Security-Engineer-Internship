Phase E: Hosted Labs Integration

Objective

Reinforce understanding of AWS IAM enumeration through practical, guided cloud security labs.

Actions Taken

1. Accessed and completed the Cybr hosted lab, [Introduction to AWS IAM Enumeration](https://cybr.com/hands-on-labs/lab/introduction-to-aws-iam-enumeration/).
2. Followed the guided lab exercises to explore AWS IAM enumeration concepts and understand how IAM-related information can be examined during security assessments.
3. Reviewed the practical application of IAM enumeration in identifying users, roles, policies, and potential permission-related security weaknesses.
4. Saved evidence of the completed Cybr lab using a screenshot of the completion dashboard.
5. Reviewed the PwnedLabs lab, [Intro to AWS IAM Enumeration](https://pwnedlabs.io/labs/intro-to-aws-iam-enumeration/). However, the lab was not attempted due to time constraints.

Key Observations

- IAM enumeration helps security analysts understand the identities, roles, policies, and permissions configured within an AWS environment.
- Examining IAM configurations can reveal excessive permissions, potentially risky access assignments, and opportunities for privilege escalation.
- Understanding IAM users, roles, and attached policies is important when assessing the security posture of an AWS account.
- Practical hosted labs help reinforce theoretical knowledge by providing guided exposure to cloud security assessment techniques.
- Completing the Cybr lab provided practical learning experience, while the PwnedLabs exercise remains outstanding for further practice.
